# MyStudio

**برنامج Windows للاتصال المرئي والصوتي باستديوهات وقاعات Cisco وSony، مع مشاركة الشاشة والتسجيل.**

الإصدار المعرّف في المشروع: **2.2.0**. يستخدم البرنامج واجهة **WinUI 3** ومحرك **OPAL** للاتصال عبر **SIP** و**H.323**، مع دعم العربية والإنجليزية واتجاه العرض المناسب لكل لغة.

## ماذا يقدم البرنامج؟

- اختيار استديو محفوظ أو إدخال عنوان الاتصال مباشرة.
- مكالمات صوت وفيديو مع التحكم في الميكروفون وصوت القاعة.
- مشاركة شاشة أو نافذة أو كاميرا، مع اختيار طريقة إرسال الشاشة والنافذة.
- مشاركة صوت الجهاز، وإلغاء الصدى وعزل الضجيج وفق قدرات المحرك والنظام.
- ضبط صوت القاعة المستقبَل حتى 300%، مع موازن صوت وإعدادات جاهزة.
- تسجيل المحتوى المشترك في ملفات MP4، مع الإيقاف المؤقت والاستئناف.
- شريط تحكم عائم للمكالمة والتسجيل، وسجل تشخيص يمكن تصديره للدعم.

دعم الجهاز والبروتوكول والترميز يعتمد على ملف دعم الاستديوهات والتفاوض الفعلي مع الطرف الآخر. وجود الميزة في البرنامج لا يضمن توافق كل جهاز أو إعداد شبكة.

## التشغيل

هذا المستودع يحتوي **ملفات المصدر**؛ لا يحتوي حاليًا على `MyStudio.exe` أو مكتبات التشغيل المجمّعة. تشغيل البرنامج يحتاج حزمة Windows مبنية مسبقًا، أو بناء المشروع بالمتطلبات الموضحة في دليل المطور.

في الحزمة المحمولة تكون البنية الأساسية:

```text
MyStudio.exe
appfiles/
  OPALData/
  Engines/Opal/NativeEngines/
```

شغّل `MyStudio.exe` مع إبقاء `appfiles` بجانبه. الحزمة المكتملة تضم مكتبات التشغيل؛ جهاز المستخدم لا يحتاج أدوات التطوير. يلزم Windows x64 متوافق، ومجلد قابل للكتابة، وأجهزة صوت وفيديو مناسبة، ومسار شبكة متاح إلى القاعة.

ملف الاتصال في البرنامج مضبوط على `Outside Connection (VPN)`، لكنه **لا ينشئ اتصال VPN**. يجب إعداد الاتصال بالشبكة خارج البرنامج. مشاركة صوت الجهاز مع استثناء صوت البرنامج تحتاج Windows build 20348 أو أحدث.

## محتويات المستودع

| المجلد أو الملف | دوره |
| --- | --- |
| `MyStudio.WinUI/` | الواجهة الرئيسية والنوافذ وأدوات المكالمة والمشاركة |
| `src/` | العقود المشتركة، وإعدادات المستخدم، وحالة العرض، وخدمات التطبيق |
| `native/opal/` | محرك الاتصال الأصلي، وإضافة AAC، والرقع والاختبارات |
| `native/media/` | أدوات التقاط ومعالجة الصوت والفيديو والتسجيل |
| `scripts/` | تجهيز الاعتمادات والبناء والتغليف وأدوات التحقق |
| `tests/` | اختبارات المشاريع المُدارة وبعض أدوات الاختبار |
| `docs/` | شروحات البرنامج وسجلات التنفيذ والتحقق والاعتمادات |
| `licenses/` | نصوص تراخيص إضافية؛ تراخيص الحزمة تُجمع أيضًا من الاعتمادات أثناء التغليف |
| `TeleStudio.slnx` | ملف الحل الذي يجمع مشاريع التطبيق والاختبارات |

## حالة التحقق

يسجل [تقرير الإصدار 2.2.0](docs/opal-validation.md) نجاح 503 اختبارات مُدارة واختبارات محلية للواجهة والوسائط. هذه نتائج موثقة من بيئة سابقة، وليست إثباتًا لإعادة تنفيذها في كل نسخة مستنسخة من المستودع؛ مجلد أدلة الإصدار المشار إليه في التقرير غير مرفق هنا حاليًا.

تظل تغطية شاشات Cisco الفعلية، ومشاركة ARM إلى Sony، وجودة الاستماع على أجهزة المستخدم نقاطًا تحتاج تحققًا فعليًا. اختبارات المحاكاة واختبارات localhost لا تثبت العرض أو جودة الصوت في القاعة البعيدة.
