## Buffers and capabilities

Outbound audio queues use fixed-size rings; negotiated send queue is capped at200ms and storage is released on teardown. Video acknowledgements are bounded to64 entries and cleared on stop. Recording pending audio is bounded to25 blocks per source; overflow ends the operation with a reported error, and pause/stop clear pending input. These code bounds are not a measured whole-process memory-leak guarantee.

AAC and1080p/4000kbps remain negotiated preferences with mono/G.722 and peer video constraints. SIP transport is an explicit capability choice; unsupported TLS or unavailable required SRTP fails visibly. No unrequested encryption downgrade or remote device reconfiguration is part of this audit.
